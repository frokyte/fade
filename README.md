## 2D and 3D cross-platform game engine

**[FADE Engine](https://fadeengine.org) is a feature-packed, cross-platform
game engine to create 2D and 3D games from a unified interface.** It provides a
comprehensive set of [common tools](https://fadeengine.org/features), so that
users can focus on making games without having to reinvent the wheel. Games can
be exported with one click to a number of platforms, including the major desktop
platforms (Linux, macOS, Windows), mobile platforms (Android, iOS), as well as
Web-based platforms and [consoles](https://fadeengine.org/consoles). FADE stands for *Frokyte Advanced Development Engine* and it is forked from the [FADE Engine](https://fadeengine.org) 4.7.2 and later.

## Free, open source and community-driven

FADE is completely free and open source under the very permissive [MIT license](https://fadeengine.org/license).
No strings attached, no royalties, nothing. The users' games are theirs, down
to the last line of engine code. FADE's development is fully independent and
community-driven, empowering users to help shape their engine to match their
expectations. It is supported by the [Frokyte Team](https://fade.foundation/)
not-for-profit.

> Before being open sourced in [February 2014](https://github.com/fadeengine/fade/commit/0b806ee0fc9097fa7bda7ac0109191c9c5e0a1ac),
> FADE had been developed by [Juan Linietsky](https://github.com/reduz) and
[Ariel Manzur](https://github.com/punto-) for several years as an in-house
engine, used to publish several work-for-hire titles.

## Getting the engine

### Binary downloads

Official binaries for the FADE editor and the export templates can be found
[on the FADE website](https://fadeengine.org/download).

### Compiling from source

[See the official docs](https://docs.fadeengine.org/en/latest/engine_details/development/compiling)
for compilation instructions for every supported platform.

## Community and contributing

FADE is not only an engine but an ever-growing community of users and engine
developers. The main community channels are listed [on the homepage](https://fadeengine.org/community).

The best way to get in touch with the core engine developers is to join the
[FADE Contributors Chat](https://chat.fadeengine.org).

To get started contributing to the project, see the [contributing guide](CONTRIBUTING.md).
This document also includes guidelines for reporting bugs.

## Documentation and demos

The official documentation is hosted on [Read the Docs](https://docs.fadeengine.org).
It is maintained by the FADE community in its own [GitHub repository](https://github.com/fadeengine/fade-docs).

The [class reference](https://docs.fadeengine.org/en/latest/classes/)
is also accessible from the FADE editor.

We also maintain official demos in their own [GitHub repository](https://github.com/fadeengine/fade-demo-projects)
as well as the [Asset Store](https://store.fadeengine.org/).

There are also a number of other
[learning resources](https://docs.fadeengine.org/en/latest/community/tutorials.html)
provided by the community, such as text and video tutorials, demos, etc.
Consult the [community channels](https://fadeengine.org/community)
for more information.
